# Beginner's guide

Open **START HERE.html** (or BEGINNER-GUIDE.html) in Chrome or Edge.

## Students
1. Switch the robot ON, wait 1 minute.
2. Connect the laptop to the robot's Wi-Fi (password `password`).
3. Click **I'm connected to the robot's Wi-Fi**.
4. Everything else happens by itself: the page sets the robot's clock,
   gets the program ready and starts it. Then follow steps 3-5 on the page.

No command window, no typing commands.

## Teacher (once per robot)
Double-click **SETUP-ROBOT (teacher, once per robot).bat**, connect to the
robot's Wi-Fi when it asks, and type `raspberry` twice. This installs a small
helper on the robot (robot-onboard/manager) that starts the program at every
power-up and lets the page compile, start, stop and update it.

New program version later: page > Teacher tools > Choose robot-onboard folder
(or run the .bat again).
