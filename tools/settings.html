Which wheel is which? Each button spins ONE wheel forward for 1 second at low power. Watch the real wheel. It should be the wheel named on the button and it should turn so the robot would go forward.

Whole robot - after all four wheels spin the right way, each button drives the robot for 0.7 s at low power. Check it goes the way the button says.

Lift and pusher

Encoder check: each Spin should make that wheel's encoder go UP by roughly 100-200 mm. Goes down? Tick that wheel's encoder reversed box (Motor directions). Doesn't change at all? That encoder cable is unplugged or on the wrong Titan port. Driving by distance only works once all four go up.
Wrong wheel moves? Change that wheel's motor port in the Wiring section below. Right wheel but spins backwards? Tick its reversed box in Motor directions. Both are saved as you go.

Which pin is which? (servos, buttons, LEDs)

Everywhere on these pages you type the pin number printed on the VMX next to the plug: FlexDIO 0-11, HiCurrDIO 12-21, Analog 0-3. The robot converts it for you. Each printed pin can be used only once.

HiCurrDIO 12-21 with its jumper removed: buttons and switches only. Servos and LEDs there need the jumper fitted - otherwise put them on FlexDIO 0-11.

2. Calibration helpers

Drive, measure with a tape, type what you measured, and the page works out the new setting for you.

Wheel size. Drive forward a known distance, then measure how far it really went.
Lift with a CONTINUOUS servo (spins all the way; tick Lift servo is in CONTINUOUS mode under Lift). Needs both lift switches working (see the live readout). Steps:
  1. Measure how far the fork travels from the bottom switch to the top switch and type it in Rail travel between the switches (Lift settings).
  2. Press Find bottom: the lift drives down until the bottom switch clicks. If it goes UP instead, swap Spin-up and Spin-down command.
  3. Press Calibrate lift: it times bottom → top → bottom and saves the up/down speeds by itself.
  4. Try the height buttons below; adjust the heights in Pick and place / Lift if needed.
No switches (or only one)? Untick the missing switch under Lift settings, then calibrate with a ruler:
  1. Press Find bottom (without a bottom switch it runs down for Time to reach the bottom).
  2. Press Run UP, then measure the fork height from the floor and type it in. Press Save up speed.
  3. Press Run DOWN, measure again, type it in. Press Save down speed.
  4. Press Find bottom once more before using the height buttons.
Lift (servo) calibration. Type a servo angle, press Try angle, and watch the fork. Find the angle where the fork is at its lowest and its highest, measure each height from the floor to the fork top, then save.
