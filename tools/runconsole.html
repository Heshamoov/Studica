Six possible orders are announced in the morning briefing; a dice roll picks one. Edit each order's task list below to match the briefing sheet — the CID's order table is confirmed on the day.

2 · Shelf layout

Run 2 uses a surprise dispensary layout (G.5). Entering it here is one of the four permitted detection routes, alongside box colour, ArUco and Code 11 — and it is the only one that cannot fail on the day. Keep it as the fallback even if vision works.

Experts do not stop the clock until the red stopped LED flashes on the robot's control panel (G.2.1 step 6). Press this when the LED is actually visible, not when the robot arrives.
